해따치고 개인정보처리방침

시행일: 2026년 10월 12일

1. 개발자가 수집하는 개인정보

해따치고 개발자는 이름, 연락처, 계정, 위치 등 이용자의 개인정보를 수집하지 않으며, 별도의 서버나 데이터베이스에 저장하지 않습니다.

2. 기기에 저장되는 정보

이용자가 입력한 금액·기간 등 계산 값과 앱 설정, 내려받은 시세 데이터는 이용자의 기기 안에만 저장됩니다. 앱을 삭제하면 함께 삭제됩니다.

3. 제3자 서비스

  • Google AdMob: 광고 제공과 성과 측정을 위해 광고 ID 등 기기 식별 정보를 수집할 수 있습니다. 자세한 내용은 Google 광고 정책을 참고하세요.
  • Google Firebase (Crashlytics, Remote Config): 앱 안정성 개선과 설정 배포를 위해 오류 기록과 기기 정보(기종, OS 버전 등)를 수집할 수 있습니다. 자세한 내용은 Firebase 개인정보 안내를 참고하세요.
  • GitHub Pages: 앱이 시세 데이터를 내려받을 때 GitHub 서버에 IP 주소 등 접속 기록이 남을 수 있습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.
