해따치고 개인정보처리방침

시행일: 2026년 10월 13일 · 최종 변경: 2026년 10월 13일

1. 개발자가 수집하는 개인정보

해따치고 개발자는 이름, 연락처, 계정, 위치 등 이용자의 개인정보를 수집하지 않으며, 개발자가 운영하는 서버나 데이터베이스는 없습니다. 회원가입·로그인 기능도 없습니다.

2. 기기에만 저장되는 정보

다음 정보는 이용자의 기기 안에만 저장되며 개발자에게 전송되지 않습니다. 기기 백업(Google 드라이브 자동 백업)에도 포함되지 않습니다.

  • 통장 기록: 참은 항목, 금액, 날짜, 메모, 루틴, 목표, 관심 종목
  • 최근 계산 기록, 공유 횟수, 앱 설정(효과음 등)
  • 내려받은 공개 시세 데이터

보유 기간: 이용자가 앱에서 삭제하거나 앱을 삭제할 때까지. 설정의 통장 초기화로 언제든 지울 수 있습니다. 통장 백업 내보내기는 이용자가 직접 선택한 앱으로만 전달되며, 개발자는 그 내용을 받지 않습니다.

3. 제3자 서비스가 처리하는 정보

각 서비스의 처리 방식은 Google 광고 정책, Firebase 개인정보 안내, GitHub 개인정보 처리방침을 따릅니다. 사용자 입력값(금액·메모 등)은 위 서비스에 전송하지 않습니다.

4. 광고 ID 거부 방법

Android 설정 → 개인정보 보호(또는 Google) → 광고 → 광고 ID 삭제를 선택하면 맞춤 광고에 광고 ID가 쓰이지 않습니다. 유럽 경제 지역 등에서는 앱 첫 실행 시 표시되는 동의 화면에서 선택할 수 있습니다.

5. 아동의 개인정보

해따치고는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.
